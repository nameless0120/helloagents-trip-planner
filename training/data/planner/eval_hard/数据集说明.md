# Planner Hard 评估集说明

## 基本信息

| 项 | 内容 |
|---|---|
| 数据集目录 | `training/data/planner/eval_hard/` |
| 样本数 | 300 |
| 失败样本 | 0 |
| split | `eval` |
| request_source | `controlled` |
| difficulty | `harder` |
| 对外定位 | hard |
| 上下文 | 当前后端生成的 PlannerContext、compact PlannerContext 和 planner_query |

本集是项目当前使用的 hard 评估集。请求、预算口径、record_id 和评估 split
固定不变，评测时直接使用本目录下的 `records.jsonl`。

## 本轮上下文变化

- 后端高端 POI 本地表进入 comfortable / premium 预算档的酒店、餐饮、景点和体验候选。
- 高预算餐饮和酒店候选经过预算感知排序，改善 hard 集 premium / comfortable 样本的候选池可达性。
- metadata 增加 `budget_context_audit`，用于审计候选池预算上限和 `high_budget_ratio`。
- 请求、预算口径、record_id 和评估 split 固定不变。
